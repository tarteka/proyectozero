## Adibidezko edukia

Fitxategi hau blogaren funtzionamendua probatzeko baino ez da: zerrenda,
artikulua, itzulpenak, estiloak eta metadatuak. Ez da benetako artikulua.

Izen bereko fitxategia egon behar du `content/blog/es/` eta
`content/blog/eu/` karpetetan, bertsio biak itzulpen gisa hartzeko.

### Zerrendak eta estekak

- Adibidezko elementu bat.
- Beste elementu bat `kode lerrokoa`-rekin.
- Esteka bat [azaleko orrira](/#top).

### Kode blokea

```ts
type Adibidea = {
  slug: string;
  locale: "es" | "eu";
};

export function adibidea(slug: string): Adibidea {
  return { slug, locale: "eu" };
}
```
